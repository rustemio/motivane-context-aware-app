# MotiVane: Context-Aware Motivation App

**MotiVane**, sıradan bir yapılacaklar listesi değil, hedeflerinizi dış dünya ile senkronize eden akıllı bir "Fikir İnkübatörü"dür. Bu proje, Ankara Üniversitesi Bilgisayar Mühendisliği Bölümü **IOS II (React Native)** dersi kapsamında geliştirilmektedir.

## 🌟 Proje Fikri
Uygulama, kullanıcının girdiği fikirleri birer "sticky note" (yapışkan not) olarak algılar. Bu notlar, özel animasyonlarla bir "Fikir Bulutu"na gönderilir. Sistem, arka planda hava durumu, konum ve zaman verilerini analiz ederek, bu fikirleri gerçekleştirmek için en uygun anı bekler ve kullanıcıyı doğru zamanda tetikler.

## 🛠 Teknoloji Yığını
- **Framework:** React Native (Expo)
- **API:** OpenWeatherMap, Google Books, Gemini AI
- **Database:** SQLite / AsyncStorage
- **Styling:** NativeWind (Tailwind CSS)
- **Animations:** React Native Reanimated
